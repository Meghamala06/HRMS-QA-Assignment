# Quality Reflection

## 1. Do you currently write tests in your own projects?

I am still learning software testing, so I have not written many automated tests in my own projects. I usually focused on completing the project first. After doing this assignment, I understood that testing is important because it helps find bugs early and improves software quality.

## 2. Describe a time you completed a project without enough testing.

In one of my college projects, I completed the features before the deadline but did only basic testing. Later, I found some small issues that could have been avoided if I had tested more carefully. This experience taught me that testing should be done throughout the project, not only at the end.

## 3. What does this team need the most?

I think the team needs a proper QA process with automated testing. Since payroll is very important, automated tests can quickly detect issues before they reach users and reduce manual work.

## 4. How would you convince a senior developer that QA is important?

I would explain that testing helps catch problems before they affect employees and payroll. I would also show an example where an automated test finds a bug early, saving time and reducing future fixes.

## 5. Connect quality to something personal in your life.

While preparing for competitive exams, I revise my subjects regularly instead of studying everything at the last minute. Regular revision helps me find mistakes and improve my understanding. Software testing is similar because checking work regularly leads to better quality and fewer problems later.
