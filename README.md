## Project Overview

This repository contains my QA Engineer assignment for an HRMS application focused on construction payroll.

The assignment demonstrates my understanding of the payroll workflow, identification of business-critical risks, preparation of a test strategy, creation of automation and API test plans, and the setup of a continuous integration (CI) pipeline.

## Objective

The objective of this assignment is to understand the construction payroll process, identify high-risk business scenarios, and design testing that improves payroll accuracy, software quality, and system reliability.
